# The Climate Case Files

**An investigation game and data tool about Mexico's changing climate, built with NASA POWER data.**
Team *Burros Espaciales* · NASA Space Apps Challenge 2026 · Challenge: *"Be an Earth System Trend Detective!"*

**Play (no sign-up, works on phones):** https://yair-naran.github.io/detective-climatico/?lang=en · Spanish: remove `?lang=en`

> Not an official NASA product. No NASA logos or mission insignia are used.

## What it is
Teenagers hear that "the climate is changing" but rarely get to check it. In The Climate Case Files the player is a young investigator who tests claims against real NASA data and then uses the findings to prepare a community for a cyclone, a heat wave or a drought.

1. **Detective's Archive (the challenge tool).** Pick a **place** (the three built-in ones, a quick pick, or *any coordinates on Earth*, loaded live from NASA POWER), a **variable** (air temperature, daily max, daily min, rainfall, relative humidity), a **season** and a **period**. The Archive draws the time series (5 chart types), fits a linear trend (Sen's slope) and tests it (Mann-Kendall). It reports change per decade and the p-value and explains in plain words what "significant" means, including that p > 0.05 does *not* prove there is no change.
2. **Three playable cases** with rising difficulty: Coast (Veracruz: cyclones), Center (Pachuca: extreme heat), North (Monterrey: drought and cold fronts). Time is limited, every choice has a cost, some claims are true and some are not supported by the data. Seven different endings per case.
3. **Things that make it different**
   - *Any place on Earth*, not only a fixed list.
   - *Hunch mode*: guess what the data will say **before** the test result is revealed, and keep a score.
   - *Compare places* side by side for the same variable, season and period.
   - *Export* the data (CSV) or the chart (PNG) for a school report.
   - It teaches **both** outcomes: significant trends (Pachuca is warming about +0.4 °C per decade) and non-significant ones (annual rainfall in Veracruz and Monterrey).
   - Original music and sounds **generated live by code** (no samples, no copyright), muted by default.
   - Works **offline** after the first visit (service worker), mobile-first, bilingual (ES/EN), no account, no backend, no tracking.
   - Accessible: Atkinson Hyperlegible font, axe-core audit with 0 WCAG 2.1 A/AA violations on the main screens, keyboard and screen-reader friendly.

## Data and method
- **Data:** NASA POWER monthly point data (`T2M`, `T2M_MAX`, `T2M_MIN`, `PRECTOTCORR`, `RH2M`), 1981 to 2026. Underlying products: MERRA-2 (NASA GMAO) and GPM IMERG. Built-in places are stored in `data/series.json` (generated by `scripts/fetch_power.py`); other places and extra variables are requested live from `https://power.larc.nasa.gov/api/temporal/monthly/point`.
- **Statistics (`js/stats.js`):** tie-corrected Mann-Kendall test with continuity correction, Sen's slope, annual or seasonal means (only complete seasons). Verified against `scipy` and `pymannkendall` for every built-in place, variable and season (`tests/stats.test.js`).
- **Limits we state in the game:** values come from a grid cell about 50 km wide, not from a weather station; MERRA-2 daily maximum is slightly underestimated and minimum slightly overestimated; trends of annual averages do not prove that any single storm or drought was caused by climate change.

## Use of AI
Code, texts and tests were written with help from Claude (Anthropic); the team reviewed, tested and edited them. The illustrations (characters, case maps, cover, medals and icons for information sources and variables) are AI-generated by the team and labeled as such in the game and in `ASSETS.md`; the animations, header logo and other icons are drawn in code. Music and sounds are synthesized by our own code (Web Audio API). Details in [`docs/ENTREGA-EN.md`](docs/ENTREGA-EN.md) and [`ASSETS.md`](ASSETS.md).

## Run it
```bash
python3 -m http.server 8080      # any static server works; then open http://localhost:8080/?lang=en
npm install && npm test          # unit tests (stats), Playwright end-to-end tests, axe accessibility audit
```
The end-to-end tests need Chrome or Chromium (set `CHROME=/path/to/chrome` if it is not found) and mock the NASA POWER API, so they run offline.
